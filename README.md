# FleetFlow NG

Enterprise Logistics Fleet Management System — Nigeria Edition

**Developer:** Ifesinachi John Nduka
**Copyright © 2026. All Rights Reserved.**

## Features
- Predictive vehicle maintenance tracking
- Driver-to-office real-time communication
- ELD data analyzer for route & fuel optimization
- Monthly / yearly enterprise subscriptions

## Setup
1. `cd backend && npm install`
2. Copy `.env.example` → `.env` and fill values
3. `npm run dev`
4. Open `frontend/index.html`

## Tech Stack
- Node.js + Express
- MongoDB (Mongoose)
- Vanilla JS frontend (TailwindCSS via CDN)
